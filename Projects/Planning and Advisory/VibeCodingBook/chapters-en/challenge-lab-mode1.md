# Challenge Lab: Mode 1

Time to put it all into practice. In this challenge, you'll use only an AI chat and a browser to build something real, from zero to deployment.

## The Challenge

Build a **personal portfolio page** with:

1. An "About me" section with photo and text
2. A list of 3 projects (they can be fictional)
3. A working contact form
4. Responsive design (works on mobile and desktop)
5. Public deployment with a shareable URL

**Estimated time**: 2-3 hours

**Allowed tools**: Only an AI chat (ChatGPT or Claude) and a browser. No IDE, no terminal.

## Suggested steps

### Step 1: Generate the structure (30 min)

Open your AI chat and ask:

> "Create a complete personal portfolio HTML page with modern CSS. I want an 'About me' section, a section with 3 project cards, and a contact form. Use a dark and minimalist design. Give me the complete HTML file with inline CSS."

Copy the code to an `index.html` file. Open it in your browser.

### Step 2: Iterate the design (30 min)

Look at the result and request changes:

- "Increase the spacing between sections"
- "Make the project cards have a placeholder image"
- "Add a hover effect on buttons"
- "Make the layout responsive for mobile"

### Step 3: Add interactivity (30 min)

Ask the chat:

> "Add JavaScript so that when the user submits the form, a success message appears and the fields are cleared. No backend needed , just client-side validation."

### Step 4: Deploy (30 min)

Use one of the methods from the deploy chapter:

1. Go to [netlify.com/drop](https://netlify.com/drop)
2. Drag your folder with `index.html`
3. Get a public URL

### Step 5: Share (5 min)

Send the URL to someone. Ask for feedback. Congratulations , you just built and launched a website with zero programming knowledge.

## Success criteria

- [ ] The page loads without errors in the browser
- [ ] The design is visually acceptable
- [ ] The form shows a success message when submitted
- [ ] It works on mobile (test by resizing the browser)
- [ ] It's online with a public URL

## Bonus (for those who want more)

- Add a dark/light mode toggle
- Add scroll animations
- Connect the form to a real service (Formspree or EmailJS)
- Add a blog section with 2-3 posts
