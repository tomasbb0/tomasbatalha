# Appendix A: Glossary

Terms are listed alphabetically. The chapter reference indicates where each term is first explained in depth.

| Term                         | Definition                                                                                                                    | Chapter |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ------- |
| **Agent**                    | An AI system that observes, decides, acts, and repeats in a loop to complete tasks                                            | 10      |
| **API**                      | Application Programming Interface: a set of endpoints for sending and receiving data between systems                          | 14      |
| **API key**                  | A credential that identifies your application to an external service                                                          | 19      |
| **ATS**                      | Applicant Tracking System: software companies use to manage job applications (Greenhouse, Lever, Workday). JobPilot's target. | 17      |
| **Auth (Authentication)**    | Verifying identity: confirming who a user is                                                                                  | 19      |
| **Authorisation**            | Verifying permission: confirming what a user can do                                                                           | 19      |
| **Backend**                  | Code that runs on a server, invisible to users                                                                                | 12      |
| **BOLA**                     | Broken Object Level Authorisation: accessing another user's data by changing an ID                                            | 18      |
| **Branch**                   | A parallel version of your code in Git                                                                                        | 16      |
| **Breakpoint**               | A marker where code execution pauses for inspection                                                                           | 21      |
| **Build step**               | The transformation from source code to deployable files (transpile, bundle, minify)                                           | 15      |
| **Bundle**                   | Combining many source files into one or two files for deployment                                                              | 15      |
| **CI/CD**                    | Continuous Integration / Continuous Deployment: automated testing and deployment                                              | 11      |
| **Client**                   | The user's browser or device                                                                                                  | 12      |
| **Commit**                   | A snapshot of your project at a specific moment in Git                                                                        | 16      |
| **Component**                | A reusable piece of user interface (React)                                                                                    | 13      |
| **Content Script**           | JavaScript injected into web pages by a browser extension                                                                     | 17      |
| **Cookie**                   | Small data stored in the browser, sent to the server with every request                                                       | 8       |
| **CORS**                     | Cross-Origin Resource Sharing: browser security that restricts requests between different domains                             | 14      |
| **CRUD**                     | Create, Read, Update, Delete: the four basic data operations                                                                  | 9       |
| **CSRF**                     | Cross-Site Request Forgery: a malicious site making requests using your authenticated session                                 | 18      |
| **CSS**                      | Cascading Style Sheets: controls the appearance of HTML elements                                                              | 4       |
| **Database**                 | Where data lives permanently on a server                                                                                      | 12      |
| **Dependency**               | Someone else's code that your project uses                                                                                    | 15      |
| **DeepSeek**                 | Open-source Chinese AI model, strong at code, free API tier                                                                   | 2, 4    |
| **Deploy**                   | Moving code to a server so users can access it                                                                                | 5       |
| **DevTools**                 | The browser's built-in development and debugging toolkit                                                                      | 8       |
| **DNS**                      | Domain Name System: translates domain names (example.com) to IP addresses                                                     | 5       |
| **DOM**                      | Document Object Model: the browser's tree representation of HTML                                                              | 8       |
| **Endpoint**                 | A specific URL that accepts API requests                                                                                      | 14      |
| **Environment variable**     | A configuration value set outside your code (.env files, platform dashboard)                                                  | 11      |
| **Event**                    | Something that happens in the browser (click, scroll, keypress, page load)                                                    | 8       |
| **Event listener**           | Code that runs when a specific event occurs                                                                                   | 8       |
| **Feature flag**             | A toggle that enables or disables a feature without redeploying                                                               | 22      |
| **fetch()**                  | The JavaScript function for making HTTP requests                                                                              | 8       |
| **Flexbox**                  | A CSS layout system for one-dimensional arrangements                                                                          | 8       |
| **Frontend**                 | Code that runs in the user's browser                                                                                          | 12      |
| **Function calling**         | Letting an AI model trigger specific functions in your code (same as tool calling)                                            | 10      |
| **Claude Code**              | Anthropic's CLI coding agent that reads your codebase and makes edits from the terminal                                       | 4       |
| **Computer use agent**       | An AI agent that controls your screen: clicks, types, scrolls, reads pixels                                                   | 10, 18  |
| **Git**                      | A version control system that tracks changes to files                                                                         | 16      |
| **GitHub**                   | A platform for hosting Git repositories with collaboration features                                                           | 16      |
| **Graceful degradation**     | Continuing to work with reduced functionality when a service fails                                                            | 20      |
| **Grid**                     | A CSS layout system for two-dimensional arrangements                                                                          | 8       |
| **Guardrails**               | Validation and safety checks applied to AI outputs                                                                            | 10      |
| **Hook**                     | A special React function (useState, useEffect) for managing state and side effects                                            | 13      |
| **Hosting**                  | The service providing the server where your app runs                                                                          | 5       |
| **HTML**                     | HyperText Markup Language: defines the structure and content of a page                                                        | 4       |
| **HTTP**                     | HyperText Transfer Protocol: how browsers and servers communicate                                                             | 14      |
| **HttpOnly**                 | A cookie flag that prevents JavaScript from reading the cookie                                                                | 19      |
| **ICP**                      | Ideal Customer Profile: the specific person your product targets                                                              | 23      |
| **Interface**                | A TypeScript definition of an object's shape                                                                                  | 13      |
| **Injection**                | Tricking an app into executing malicious input as code                                                                        | 18      |
| **JavaScript**               | The programming language that adds interactivity to web pages                                                                 | 4       |
| **JSON**                     | JavaScript Object Notation: the standard format for data exchange                                                             | 14      |
| **JWT**                      | JSON Web Token: a signed, self-contained token carrying user information                                                      | 19      |
| **Kill switch**              | A feature flag designed for emergency shutoff                                                                                 | 22      |
| **localStorage**             | Browser storage that persists across sessions (~5 MB, same domain only)                                                       | 9       |
| **Logging**                  | Recording what your app does (requests, errors, events)                                                                       | 11      |
| **Manifest V3 (MV3)**        | The current Chrome extension architecture standard                                                                            | 17      |
| **Merge**                    | Combining changes from one Git branch into another                                                                            | 16      |
| **Merge conflict**           | When two branches modify the same line and Git needs manual resolution                                                        | 16      |
| **Message passing**          | How a browser extension's contexts communicate                                                                                | 17      |
| **MCP**                      | Model Context Protocol: Anthropic's open standard for connecting AI to external tools                                         | 10      |
| **Minification**             | Reducing code size by shortening variable names and removing whitespace                                                       | 15      |
| **Mode 1**                   | Vibe coding by copying AI-generated code into files                                                                           | 1       |
| **Mode 2**                   | Using generative platforms (Lovable, Bolt, v0) to build apps                                                                  | 1, 7    |
| **Mode 3**                   | Coding in a full IDE with AI assistance                                                                                       | 1       |
| **Model routing**            | Sending easy tasks to cheap AI models and hard tasks to expensive ones                                                        | 20      |
| **MVP**                      | Minimum Viable Product: the smallest thing that tests a hypothesis                                                            | 23      |
| **node_modules/**            | The folder where npm stores downloaded packages                                                                               | 15      |
| **npm**                      | Node Package Manager: installs and manages JavaScript packages                                                                | 15      |
| **OAuth 2.0**                | The standard protocol for delegated authentication ("Login with Google")                                                      | 19      |
| **Observability**            | Understanding an app's internal state from its external outputs                                                               | 11      |
| **OpenClaw**                 | Open-source autonomous AI agent (247K GitHub stars) that controls your computer via messaging apps                            | 10      |
| **OWASP**                    | Open Worldwide Application Security Project                                                                                   | 18      |
| **package.json**             | The file that lists a Node.js project's dependencies and configuration                                                        | 15      |
| **Permissions**              | The capabilities a browser extension requests from the user                                                                   | 17      |
| **Popup**                    | The small UI shown when clicking a browser extension's icon                                                                   | 17      |
| **Props**                    | Data passed from a parent React component to a child                                                                          | 13      |
| **Prompt caching**           | Reusing cached system prompts to reduce AI API costs                                                                          | 20      |
| **Pull Request (PR)**        | A proposal to merge changes with a review step on GitHub                                                                      | 16      |
| **Rate limit**               | Maximum number of API requests allowed per time period                                                                        | 14, 20  |
| **Repository (repo)**        | A project folder tracked by Git                                                                                               | 16      |
| **Responsive design**        | CSS that adapts layout to different screen sizes                                                                              | 8       |
| **REST**                     | A convention for organising API endpoints around resources                                                                    | 14      |
| **Rollback**                 | Reverting to a previous working state                                                                                         | 22      |
| **Row-Level Security (RLS)** | Database rules controlling which users access which rows (Supabase)                                                           | 9       |
| **Scope creep**              | Unplanned expansion of project features                                                                                       | 23      |
| **Semantic HTML**            | Using HTML tags that describe meaning (nav, article, footer)                                                                  | 4       |
| **SemVer**                   | Semantic Versioning: major.minor.patch version numbering                                                                      | 15      |
| **Sentry**                   | An error monitoring service that captures exceptions with context                                                             | 11      |
| **Server**                   | A computer that's always on, waiting for requests                                                                             | 12      |
| **Service Worker**           | A browser extension's background script (MV3)                                                                                 | 17      |
| **Session**                  | The server's record that a user is logged in                                                                                  | 19      |
| **sessionStorage**           | Browser storage that dies when the tab closes                                                                                 | 9       |
| **SQL injection**            | Injecting database commands through user input                                                                                | 18      |
| **SSL/HTTPS**                | Encryption securing data between browser and server                                                                           | 5       |
| **Stack trace**              | The list of function calls that led to an error                                                                               | 21      |
| **State**                    | The data an app knows right now                                                                                               | 9, 13   |
| **Static site**              | A site made of pre-built HTML, CSS, and JS files with no backend                                                              | 5       |
| **Structured output**        | Forcing an AI to respond in a specific JSON format                                                                            | 10      |
| **Tailwind CSS**             | A utility-first CSS framework for styling directly in HTML                                                                    | 13      |
| **Token**                    | A unit of text for AI billing (~0.75 words per token)                                                                         | 20      |
| **Tool calling**             | Letting an AI decide when to trigger functions in your code                                                                   | 10      |
| **Transpilation**            | Converting code from one language to another (TypeScript → JavaScript)                                                        | 15      |
| **Tree shaking**             | Removing unused code from the final bundle                                                                                    | 15      |
| **TypeScript**               | JavaScript with type annotations for compile-time error checking                                                              | 13      |
| **Unit test**                | Testing one function in isolation with specific inputs and expected outputs                                                   | 21      |
| **Uptime monitoring**        | A service that checks if your site is online and alerts you when it's not                                                     | 11      |
| **URL parameters**           | Data in the URL (example.com/search?q=coffee) that represents shareable state                                                 | 9       |
| **useState**                 | A React hook that lets a component track and update data                                                                      | 13      |
| **useEffect**                | A React hook that runs code in response to changes                                                                            | 13      |
| **Vite**                     | A modern build tool for web projects                                                                                          | 15      |
| **XSS**                      | Cross-Site Scripting: injecting JavaScript into pages other users see                                                         | 18      |
